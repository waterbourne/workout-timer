🔥 AB Workout Timer

A beautiful, production-ready progressive web app for interval-based workouts with automatic scheduling, exercise demonstrations, and audio cues.

📦 View on GitHub 🚀 Try Live Demo

🎯 Smart Scheduling

Automatically loads the right workout based on time of day. Set your schedule (e.g., 5am, 8am, 11am) and the app rotates through workouts intelligently.

⏱️ Professional Timer

30-second prep, 45-second work intervals, 15-second rest. Audio beeps for transitions, visual progress bars, and phase indicators keep you locked in.

💪 Exercise Library

Detailed form cues, safety tips, and breathing guidance for every exercise. Know exactly what to do and how to do it right.

📱 Mobile-First PWA

Installs like a native app, works offline, prevents accidental refresh. Dark theme with high contrast for gym lighting.

🎨 Zero Dependencies

Pure vanilla JavaScript. No frameworks, no build process, no npm. Just drop the files and serve.

🤖 Agent-Ready

Includes AGENTS.md with complete setup instructions. Your AI agent can clone, customize, and deploy this app automatically.

Get Started in 30 Seconds

Clone, serve, and workout. It's that simple.

# Clone the repo
git clone https://github.com/waterbourne/workout-timer
# Serve it
cd workout-timer && python3 -m http.server 8080
# Open in browser
http://localhost:8080
